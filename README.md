# Music Analysis and Mood-Based Recommendation System

A Python project that analyzes Spotify track data and recommends songs based on a selected mood.

## Features

- Loads and cleans the Spotify tracks dataset.
- Filters tracks by a user-selected starting year.
- Displays a correlation heatmap for available audio features.
- Plots top artists by average popularity.
- Recommends up to five songs for a selected mood: Happy, Sad, or Chill.

## Files

- `music_analysis_project.py` — main Python program.
- `tracks.csv.gz` — compressed dataset. Keep it in the same folder as the Python file.

## Requirements

- Python 3.9 or later
- pandas
- matplotlib
- seaborn

## Setup and Run

1. Install Python if it is not already installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Install the required libraries:

   ```bash
   pip install pandas matplotlib seaborn
   ```

5. Run the program:

   ```bash
   python music_analysis_project.py
   ```

6. Enter a starting year when prompted, then enter the number of top artists to display.
7. Choose a mood:
   - `1` — Happy
   - `2` — Sad
   - `3` — Chill

The program reads `tracks.csv.gz` directly; you do not need to extract it first.

## Notes

- Keep `music_analysis_project.py` and `tracks.csv.gz` in the same folder.
- The CSV should contain columns such as `name`, `artists`, `popularity`, and `release_date`. Mood recommendations also use `valence`, `danceability`, and `energy`.
- Recommendations are based on audio-feature thresholds and popularity ranking; they are not generated by a trained machine-learning model.
